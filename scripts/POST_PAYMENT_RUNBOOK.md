# Post-payment runbook — completing the live Data Store load

Once the Catalyst payment method / hack2skill credits are active, the free-tier
quota errors ("Datastore - Bulk Write" / "Datastore - Insert") disappear.
Everything below is already scripted; total time ≈ 15–30 min, mostly waiting.

## 0. Preconditions
- Payment method visible under Zoho Store / Catalyst billing for org `60079891305`.
- You are logged in: `catalyst whoami` → `basuoikantik@gmail.com`.

## 1. Confirm the quota is lifted (2 min)
```bash
node scripts/load_via_api.mjs "https://project-rainfall-60079891305.development.catalystserverless.in/server/dappa_api" --only=CasteMaster
```
CasteMaster is tiny (a handful of rows). If it completes without an
`exhausted the free tier allowance` error, quotas are live.

## 2. Fix the AggMonthly resume point (avoids ~1k duplicate rows)
The interrupted run stopped at 5,000 rows but the state file may say 4,000.
Check the REAL count (healthz `dataCompleteness` if present, or the console's
Data Store row count for AggMonthly), then set it exactly:
```bash
node -e "const f='scripts/.apiload_state.json',s=require('fs');const j=JSON.parse(s.readFileSync(f,'utf8'));j.AggMonthly=<REAL_COUNT>;s.writeFileSync(f,JSON.stringify(j,null,1))"
```

## 3. Run the full load (resumable; re-run if interrupted)
```bash
node scripts/load_via_api.mjs "https://project-rainfall-60079891305.development.catalystserverless.in/server/dappa_api"
```
Loads in priority order: analytics tables → case children → remaining ER
tables (~250k rows total, ~200 rows/request). Progress persists in
`scripts/.apiload_state.json`.

once all match), then:

## 6. Optional Catalyst AI upgrades (console-only, docs/CONSOLE_SETUP.md)

## Known quirks (hard-won)
- Data Store **Boolean columns reject `1/0`** — use `pipeline/.bool_fixed/`
  CSVs (already generated by `scripts/fix_bools.mjs`).
- `catalyst ds:import` prompts interactively for the Stratus bucket — pipe
  stdin (`printf '\nN\n' | catalyst ds:import ...`) or use
  `scripts/import_all.mjs` which handles it.
- Re-uploading the same filename to Stratus → HTTP 409; `import_all.mjs`
  uses unique names per run.
- Console/Data Store `table_id`s exceed JS safe-integer range — treat as
  strings, never `JSON.parse` into numbers.
